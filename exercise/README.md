# Exercism exercises

Mỗi bài nằm trong một thư mục riêng để có thể dùng chung tên kiểu và hàm
giữa các bài mà không gây xung đột khi biên dịch.

## Chạy từng bài

Mỗi bài có file `main.go` ngay trong thư mục của bài. Từ thư mục `exercise`,
chạy ví dụ:

```bash
go run ./cards-trick
```

Các lệnh tương ứng:

```bash
go run ./bird-watcher
go run ./need-for-speed
go run ./blackjack
go run ./cars-assemble
go run ./lasagna-master
go run ./cards-trick
go run ./gross-store
go run ./vehicle-purchase
go run ./jetliks-toy
go run ./booking-beauty
```

Bạn sửa input trong file `main.go` của bài đang học rồi chạy lại lệnh tương ứng.
